QUICK START (5 minutes)
================================================================================

1. Copy to your project:
   cp -r /mnt/user-data/outputs/distribution-resource/src/* your-project/src/

2. Install dependencies:
   npm install react-katex katex framer-motion lucide-react

3. Add to your page:
   import { DistributionTable } from '@/components/DistributionTable';
   export default function DistributionsPage() {
     return <DistributionTable />;
   }

4. Add CSS (in _app.tsx or layout.tsx):
   import '@/styles/distributions.css';

5. Test:
   npm run dev
   Visit http://localhost:3000/distributions

6. Click on "Uniform (Continuous)" to see the example derivation!
